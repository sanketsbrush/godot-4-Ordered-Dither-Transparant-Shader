  To use this shader:  
  -Make "DitherTexture.png" using provided gdscript.  
  -Import "DitherTexture.png" with lossless compression.  
  -Put "DitherTexture.png" in shader of your choice.  
  
  'DitherAlphaShader1.tres' is basic shader with no textures.  
  'DitherAlphaShader2.tres' is complex shader with textures.
